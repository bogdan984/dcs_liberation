# DCS Liberation — подробное руководство на русском

Это руководство к русской версии DCS Liberation из этого репозитория. В нём:
как установить программу, связать её с DCS World (версия с официального сайта),
создать кампанию, планировать вылеты, запускать миссии в DCS и сохранять результаты,
а также расшифровка всех обозначений, которые остались на английском.

Актуально для DCS World 2.9.27–2.9.28 (лето–осень 2026 г.) и DCS Liberation 15.x/16.x.

## 1. Что такое DCS Liberation

DCS Liberation — бесплатная программа, которая превращает DCS World в
**динамическую кампанию**. Вы выбираете театр военных действий (карту),
две противоборствующие стороны (фракции) и эпоху. Дальше игра идёт **по ходам**:

1. В Liberation вы покупаете технику, распределяете эскадрильи, планируете вылеты.
2. Liberation генерирует обычную миссию DCS (`.miz`).
3. Вы летаете эту миссию в DCS World — в одиночку или с друзьями.
4. После выхода из миссии Liberation считывает, что уничтожено и захвачено,
   двигает линию фронта и начинает следующий ход.

Цель — захватить все контрольные точки (аэродромы, передовые базы, авианосцы) противника.

Важно: **засчитывается только то, что произошло, пока миссия была запущена.**
Если выйти из миссии раньше, незавершённые задания не будут «досчитаны».

## 2. Что нужно для игры

- **Windows 10 или 11 (64-бит).** Программа собирается только под Windows.
- **DCS World**, установленный с официального сайта
  [digitalcombatsimulator.com](https://www.digitalcombatsimulator.com/) (standalone-версия).
  Версия DCS должна быть не старше той, что указана в описании релиза Liberation
  (например, Liberation 15.0.0 рассчитан на DCS 2.9.27, Liberation 16.0.0 — на DCS 2.9.28).
- **Карта (терейн)** выбранной кампании. Бесплатно в DCS есть Кавказ и Марианские острова;
  остальные карты (Персидский залив, Сирия, Невада, Нормандия, Ла-Манш, Южная Атлантика,
  Синай, Кола, Германия времён холодной войны и т. д.) — платные модули.
- **Модули самолётов/вертолётов**, на которых вы хотите летать. ИИ может летать
  на любой технике, даже если у вас нет её модуля; модуль нужен только чтобы сесть в кабину самому.
- Модуль **Supercarrier** — по желанию (для реалистичных авианосцев).
- Хороший компьютер: кампании Liberation создают много юнитов. Каждая кампания
  в мастере показывает «Нагрузку на ПК» по шкале от 0 до 3.

## 3. Где DCS World хранит файлы (версия с официального сайта)

С версии DCS 2.9 разделение на «Stable» и «Open Beta» отменено: есть одна
версия **DCS World**. Поэтому у standalone-установки теперь две основные папки.

### Папка установки DCS

По умолчанию:

```
C:\Program Files\Eagle Dynamics\DCS World
```

Если вы ставили игру на другой диск, путь будет другим. Как найти:
щёлкните правой кнопкой по ярлыку DCS World → **Расположение файла**.
Откроется папка `...\DCS World\bin` — вам нужна папка **на уровень выше**
(в ней лежат `bin`, `Scripts`, `Mods`, `Config`).

Старые установки Open Beta могли называться `DCS World OpenBeta` — это тоже нормально.

### Папка Saved Games (пользовательская папка DCS)

```
C:\Users\<Ваше_имя>\Saved Games\DCS
```

Здесь DCS хранит настройки управления, логи, миссии и ливреи. Внутри:

| Папка | Что там |
|---|---|
| `Missions` | Сгенерированные миссии, в том числе `liberation_nextturn.miz` |
| `Liberation` | Данные DCS Liberation: сохранения кампаний (`Saves`), свои эскадрильи, фракции, кампании, журнал |
| `Logs` | Логи DCS (`dcs.log`) — пригодятся при поиске ошибок |
| `Liveries` | Свои ливреи |
| `Config` | Настройки игры и управления |

Если на компьютере когда-то стояла Open Beta, может остаться и папка
`Saved Games\DCS.openbeta`. Liberation сам выбирает `DCS.openbeta`, если она есть.
Чтобы понять, какой папкой реально пользуется DCS, посмотрите, где свежее файл
`Logs\dcs.log`, и укажите именно эту папку в настройках Liberation (раздел 5).

## 4. Установка DCS Liberation

1. Откройте страницу релизов этого репозитория:
   **Releases** → последний релиз с пометкой **«русская версия»** (тег вида `15.0.0-ru`).
2. Скачайте архив `dcs_liberation.<версия>-ru.zip`.
3. Распакуйте его **не** в `Program Files`. Рекомендуемое место:
   ```
   C:\Users\<Ваше_имя>\Saved Games\dcs_liberation
   ```
   Программе нужно писать файлы в свою папку, а в `Program Files` это требует прав администратора.
4. Запустите `liberation_main.exe`.
   - Если Windows SmartScreen пишет «Windows защитила ваш компьютер» —
     нажмите **Подробнее → Выполнить в любом случае** (программа не подписана сертификатом).
   - Антивирус иногда ругается на программы, собранные PyInstaller. Добавьте папку
     Liberation в исключения, если файл удаляется.
5. Вместе с программой открывается чёрное окно консоли — это журнал работы.
   Не закрывайте его: закроется и программа.

Каждую новую версию распаковывайте в **отдельную** папку. Сохранения кампаний
хранятся не в папке программы, а в `Saved Games\DCS\Liberation\Saves`, поэтому
старую папку программы можно спокойно удалить.

## 5. Первый запуск и файл MissionScripting.lua

### Окно «Первоначальная настройка»

При первом запуске появится окно с предупреждением и двумя полями:

- **Папка Saved Games DCS** — укажите `C:\Users\<Ваше_имя>\Saved Games\DCS` (см. раздел 3).
- **Папка установки DCS** — укажите `C:\Program Files\Eagle Dynamics\DCS World`
  (или ваш путь; папка, в которой лежат `bin` и `Scripts`).
- **Тема (нужен перезапуск)** — оформление окна.

Нажмите **«Я всё прочитал(а) и принимаю»**. Позже эти пути можно поменять:
**Файл → Параметры**.

### Зачем Liberation меняет MissionScripting.lua

Чтобы узнать результаты миссии, скрипт внутри миссии должен записать файл
`state.json` на диск. По умолчанию DCS запрещает миссиям доступ к файлам (модули
`os`, `io`, `lfs`). Поэтому Liberation:

- **при запуске** подменяет файл `<папка установки DCS>\Scripts\MissionScripting.lua`
  своей версией с разрешённым доступом к файлам;
- **при закрытии** возвращает оригинальный файл (копия лежит в
  `<папка Liberation>\resources\scripts\MissionScripting.original.lua`).

Это не мешает проходить проверку целостности на серверах. Но, пока Liberation
запущен, **не заходите на незнакомые серверы и не открывайте чужие миссии**:
в изменённом режиме миссия теоретически может получить доступ к вашим файлам.

### Три главных правила

1. **Сначала запускайте Liberation, потом DCS.** DCS читает `MissionScripting.lua`
   при старте. Если DCS уже был запущен, результаты миссии не запишутся.
2. **После обновления DCS** (апдейтер перезаписывает `MissionScripting.lua`)
   закройте и DCS, и Liberation и запустите их заново в правильном порядке.
3. Если программа пишет, что не может изменить файл, — запустите
   `liberation_main.exe` **от имени администратора** (особенно если DCS стоит в
   `Program Files`). Можно поставить галочку в свойствах ярлыка → Совместимость →
   «Запускать эту программу от имени администратора».

Если оставить папку установки DCS пустой, Liberation не будет трогать файл, и тогда
его надо править вручную (раздел 19).

## 6. Создание новой кампании (мастер)

**Файл → Новая игра** (или кнопка на панели инструментов). Мастер состоит из страниц.

### Введение
Просто нажмите **Далее**. Перед созданием новой кампании сохраните текущую.

### Театр военных действий
- Слева список кампаний. Значок показывает карту.
  Кампании с пометкой **[НЕСОВМЕСТИМО]** сделаны для другой версии Liberation;
  они скрыты, пока не отмечено «Показать несовместимые кампании».
- Справа — **автор**, состояние кампании («Кампания актуальна» или предупреждение),
  **фракции по умолчанию**, описание и **нагрузка на ПК** (0 — лёгкая, 3 — огромная).
- **Поменять стороны** — игрок начнёт за противоположную сторону карты.
- **Продвинутая ПВО (IADS)** — включает связанную систему ПВО: радары, командные
  пункты, линии связи и питания. Если кампания её не поддерживает, флажок недоступен.
- **Период**: либо **Дата начала** вручную, либо **Готовый период**
  (ВМВ, холодная война, война в Заливе, современность и т. д.).
  Дата влияет на доступность оружия (если включено «Ограничить оружие по дате»),
  а также на время восхода и заката.

### Выбор фракций
- **Фракция игрока** и **Фракция противника** — наборы техники, ПВО, кораблей
  (например, «USA 2005», «Russia 2010»). По умолчанию стоят фракции, задуманные автором кампании.
- Ниже — список возможных ЛА, техники и ПВО фракции. Какие ЛА реально будут
  в игре, решает кампания: в списке показаны допустимые, а не обязательно доступные.

### Настройки генератора
- **Без авианосцев / Без УДК** — не создавать авианосцы или универсальные десантные корабли.
- **Использовать модуль Supercarrier** — если он у вас куплен.
- **Без флота игрока / Без флота противника** — не создавать боевые корабли.
- **Желаемая длительность миссии** — сколько минут после начала хода будут
  действовать патрули, заправщики и т. п. (подробнее в разделе 18).
- **Моды** — отметьте установленные у вас моды самолётов (A-4E, F-22A, Су-57 и т. д.).
  Ставьте галочку, только если мод действительно установлен в
  `Saved Games\DCS\Mods\aircraft`, иначе миссия не запустится.

### Сложность и автоматизация
- **Множитель дохода игрока/противника** — во сколько раз увеличить доход за ход.
- **Стартовый бюджет игрока/противника** — деньги на начало кампании.
  Больше денег — больше техники в миссиях и больше нагрузка на ПК.
- **Помощь игроку**:
  - **Автоматический ремонт ВПП**;
  - **Автоматические закупки для фронта** (наземные войска);
  - **Автоматические закупки ЛА**.
  Всё это можно поменять позже в настройках.

### Плагины
Lua-скрипты, которые добавляются в миссию. Включаются флажком рядом с названием
(описание плагинов — в разделе 22).

### Завершение
Нажмите **Завершить** — начнётся генерация кампании (может занять минуту).

## 7. Настройка авиакрыла

После генерации откроется окно **«Настройка авиакрыла»**. **Это единственная
возможность изменить состав эскадрилий** — позже добавить эскадрилью нельзя.

Вкладки **Синие** (ваша сторона) и **Красные** (противник). Слева — типы задач,
справа — эскадрильи. Для каждой эскадрильи можно задать:

- **Название**, **Прозвище** (кнопка «Другое прозвище» — случайное), **Ливрея**;
- **Макс. размер** — сколько ЛА может быть в эскадрилье;
- **Основная задача**;
- **База** — где она базируется (число рядом — занятые/всего стоянок);
- **Игроки** — имена пилотов-игроков, по одному в строке (пусто — только ИИ);
- **Типы задач для автоназначения** — на какие задачи автопланировщик может её брать.

Кнопки: **Добавить эскадрилью**, **Удалить эскадрилью**, **Заменить на шаблон**
(готовые эскадрильи из `resources\squadrons`), **Сбросить изменения**,
**Принять изменения и начать кампанию**.

Если на каком-то аэродроме больше ЛА, чем стоянок, программа не даст продолжить
и покажет «Переполненные аэродромы».

Сразу после этого рекомендуем сохранить игру: **Файл → Сохранить**.

## 8. Главное окно программы

### Меню и панель инструментов
- **Файл**: Новая игра, Открыть, Сохранить, Сохранить как, Параметры, Выход.
- **Инструменты разработчика**: Импорт компоновок (для авторов кампаний).
- **Справка**: Сервер Discord, Репозиторий Github, Украина, Релизы, Онлайн-руководство,
  Тема на форуме ED, Сообщить об ошибке, Показать журнал, О DCS Liberation.
- Панель **Действия**: **Настройки** (настройки кампании), **Статистика** (графики
  потерь по ходам), **Заметки** (появятся на планшете в кабине), **Авиакрыло**,
  **Переброски**.

### Верхняя панель
- **Ход N** — номер хода, дата и время суток (рассвет/день/закат/ночь).
- Погода: ветер **у земли**, на **FL08** и **FL26** (это слои ветра DCS на высоте
  2000 м и 8000 м), облачность, осадки, туман. Наведите мышь — увидите нижнюю границу облаков.
- **Бюджет** — деньги; щелчок открывает «Финансы» (откуда идёт доход).
- **Разведка** — соотношение сил в воздухе, на фронте и в экономике;
  щелчок открывает подробные данные, флажок «Показать данные противника».
- **Фракции** — кто за кого играет.
- **Действия**: **Макс. игроков** (число слотов игроков в миссии),
  **Пропустить ход / Завершить ход**, **Взлёт** (сгенерировать миссию).

### Левая панель — ATO (план воздушных операций)
- **Пакеты** — все запланированные пакеты (подробно в разделе 10).
  Кнопки **Изменить** и **Отменить/прервать**.
- **Звенья** — звенья выбранного пакета. Кнопки **Изменить** и **Отменить**.
  Клавиша Delete отменяет выбранный пакет или звено.

### Карта
- Щелчок **левой** кнопкой по своей базе — меню базы (покупки, переброски).
- Щелчок **правой** кнопкой по цели (база, объект, линия фронта) — создать пакет на эту цель.
- Справа вверху — список слоёв: контрольные точки, авиация, ПВО, зоны поражения ЗРК,
  линии фронта, пути снабжения, планы полётов синих/красных, зоны угроз и т. д.
- Линейка «Расстояние» — для измерения дистанций.
- Цвета: синие — свои, красные — противник. Красная линия от базы к фронту —
  путь снабжения фронта; белая — путь колонн/снабжения между своими базами.

### Нижняя панель — информационная панель
Сообщения игры: начало хода, подкрепления, захваты баз, сводки с фронта, ремонт ВПП.

## 9. Ход 0: закупки и подготовка

На ходе 0 миссия не летается — это подготовка. Кнопка называется **«Начать кампанию»**.

### Меню базы
Щелчок левой кнопкой по своему аэродрому. Вкладки:

- **Командование аэродрома** — покупка/продажа ЛА (кнопки «+» и «−»).
  Shift или Ctrl — купить/продать сразу несколько.
  - Купленные ЛА прибудут **на следующий ход**.
  - **Продажа происходит сразу и отменить её нельзя.**
  - Покупать можно, только если на базе есть эскадрилья этого типа.
  - Лимит — деньги и число стоянок.
- **Штаб сухопутных войск** — покупка наземной техники для фронта и выбор
  **тактики на линии фронта** (раздел 15).
- **Вертодром** — для передовых баз (FOB) с вертолётными площадками.
- **Разведка** — что есть на базе.
- **Отправляемые колонны** — колонны, которые уходят с базы (у противника — их можно атаковать).

Внизу: **Перебросить войска**, у вражеской базы — **Атаковать аэродром**,
а также состояние ВПП и кнопка ремонта («Починить ВПП», $100M, 4 хода).

### Что купить в начале
- Самолёты для **всех** задач вашей стороны, а не только для себя:
  истребители для патрулей (CAP), штурмовики для CAS, самолёты для подавления ПВО (SEAD/DEAD).
- Наземные войска на базы, связанные с активной линией фронта: без них фронт не двигается.

Потратьте бюджет и нажмите **«Начать кампанию»**.

## 10. Планирование вылетов: пакеты и звенья

### Термины
- **Звено (flight)** — группа из 1–4 ЛА одного типа с одной задачей.
- **Пакет (package)** — несколько звеньев, работающих по одной цели. Например,
  удар по заводу: звено Strike (бомбит), звено SEAD (подавляет ПВО), звено Escort (прикрывает).
- **ATO** — все пакеты стороны на этот ход.
- **TOT (Time Over Target)** — время над целью. От него рассчитываются время взлёта,
  точки сбора и т. д. Для ударных звеньев — время попадания по цели, для CAP — начало патрулирования.

### Автопланировщик
Если в настройках включено «Автоматическое планирование пакетов», программа сама
создаёт пакеты на каждый ход. Вы можете их менять, удалять и добавлять свои.

### Как создать пакет
1. Щёлкните **правой** кнопкой по цели на карте (вражеский объект, ЗРК, аэродром,
   линия фронта, или свой объект для BARCAP).
2. В окне **«Пакет задания»**:
   - **Тип пакета** определяется первым звеном;
   - **Время над целью** — TOT относительно начала миссии;
   - флажок **ASAP** — «как можно скорее»: TOT ставится на самое раннее время,
     когда все звенья успевают к цели;
   - **Добавить звено**, **Удалить выбранное**, **Удалить пакет**, **Готово**.
3. **Добавить звено** открывает **«Создать звено»**:
   - **Задача** — тип задания (CAS, Strike, SEAD… см. словарь);
   - **ЛА** — тип самолёта;
   - **Эскадрилья** — откуда берутся ЛА и пилоты;
   - **Запасной** — запасной аэродром;
   - **Размер** — число ЛА;
   - **Назначенные пилоты**;
   - **Тип старта**: **Холодный** (с выключенными двигателями), **Горячий**
     (двигатели запущены), **С ВПП**, **В воздухе**. Всё, кроме холодного, делает звено
     невидимым для ударов OCA/Aircraft — это влияет на баланс;
   - **Своё название звена** (необязательно, без символа `|`).

### Редактирование звена
Двойной щелчок по звену. Вкладки:
- **Общие настройки звена** — слоты и пилоты, тип старта, позывной ведущего,
  **смещение TOT** относительно пакета, аэродромы вылета/посадки/запасной;
- **Подвеска** — вооружение по пилонам. «Своя подвеска», «Одинаковая подвеска
  для всего звена» (у ИИ подвеска должна быть одинаковой), коды лазера;
- **Путевые точки** — маршрут. Можно пересоздать маршрут, добавить точку возврата (RTB),
  удалить точки, добавить готовую точку. Названия точек — в словаре.

### Тайминг
- ИИ-звенья с суши, которым ещё рано, стоят на стоянке без экипажа до своего времени
  (их можно уничтожить ударом по аэродрому).
- Звенья ИИ с авианосца появляются только к своему времени.
- Звено игрока с холодным стартом с суши тоже ждёт: **в кабину нельзя сесть до
  времени старта** звена (оно видно в окне звена).
- Чтобы не ждать, включите «Звенья игроков игнорируют TOT и появляются сразу»
  (Настройки → Генератор миссий). Расписание миссии от этого не меняется, вы просто
  ждёте в кабине.

## 11. Как стать пилотом звена (слот игрока)

В Liberation игрок — это **пилот эскадрильи с отметкой «Игрок»**.

1. Выберите пакет на панели **Пакеты**, затем звено на панели **Звенья**,
   нажмите **Изменить** (или двойной щелчок).
2. В блоке **Слоты** у нужного пилота поставьте флажок **Игрок**.
   Если свободных пилотов-игроков нет, флажок превращает выбранного пилота в игрока.
3. Пилотов можно также сделать игроками в окне **Авиакрыло** → двойной щелчок по
   эскадрилье → «Сделать игроком».

Если вы забыли назначить себя, при нажатии **Взлёт** программа спросит
«Продолжить без пилотов-игроков?» — тогда миссия будет только для ИИ.

По умолчанию пилоты игроков не погибают (настройка «Пилоты игроков не могут погибнуть»),
но **самолёт всё равно теряется**, если его сбили.

## 12. Запуск миссии в DCS World

1. Убедитесь, что Liberation запущен **раньше** DCS (раздел 5).
2. В Liberation нажмите **Взлёт**.
   - Если у некоторых звеньев время старта раньше начала миссии, программа предложит
     **«Исправить TOT автоматически»** или **«Продолжить без исправлений»**.
   - Если включено ускорение времени, программа сначала «прокрутит» симуляцию.
3. Появится окно **«Ожидание завершения миссии»** с инструкцией.
   **Не закрывайте его, пока не закончите миссию!** Сгенерированная миссия
   действительна, только пока открыто это окно.
4. Liberation записал миссию в файл:
   ```
   C:\Users\<Ваше_имя>\Saved Games\DCS\Missions\liberation_nextturn.miz
   ```
5. Запустите DCS World и откройте миссию одним из способов:
   - **Главное меню → МИССИЯ** (Mission) → в списке слева папка **My Missions**
     (это и есть `Saved Games\DCS\Missions`) → `liberation_nextturn` → **OK**;
   - **Главное меню → РЕДАКТОР МИССИЙ → Файл → Открыть** → `liberation_nextturn.miz` →
     затем кнопка запуска (Полёт / Fly);
   - для игры с друзьями — **МУЛЬТИПЛЕЕР → Новый сервер** → выбрать эту миссию (раздел 19).
6. Выберите свой слот (если он один — выберется сам). Брифинг содержит сведения о звене.
7. В кабине откройте **планшет (kneeboard)**: по умолчанию `RShift + K`,
   страницы листаются `[` и `]`. На планшете — маршрут, частоты, цели, ваши заметки.
8. Выполните задание, вернитесь на базу (RTB) и выйдите из миссии.
   Лучше дождаться, пока основные события закончатся: всё, что не случилось
   во время миссии, не засчитается.

Если план нужно поменять, закройте окно ожидания («Прервать миссию»), измените план
и снова нажмите **Взлёт**. **Миссию в DCS после этого нужно открыть заново** — файл перезаписан.

## 13. Как сохранять миссии и кампании

### Сохранение кампании Liberation
- **Файл → Сохранить** / **Сохранить как** — файл `*.liberation.zip`.
- По умолчанию сохранения лежат в:
  ```
  C:\Users\<Ваше_имя>\Saved Games\DCS\Liberation\Saves
  ```
- Там же программа автоматически ведёт `autosave.liberation.zip`.
- **Файл → Открыть** — загрузить кампанию.
- Сохраняйтесь **до** нажатия «Взлёт» и после принятия результатов. Если миссия
  пошла не так, можно загрузить сохранение и переиграть ход.
- Сохранения **не переносятся между основными версиями** Liberation (например,
  кампания из 15.x не откроется в 16.0). Доиграйте кампанию на старой версии
  или начните новую. Поэтому старую папку программы стоит держать, пока идёт кампания.

### Сохранение сгенерированной миссии DCS
Миссия каждого хода — обычный файл DCS. При каждом нажатии «Взлёт» Liberation
**перезаписывает** `Saved Games\DCS\Missions\liberation_nextturn.miz`.

- Чтобы оставить миссию себе (например, переиграть позже как отдельную миссию
  или отдать другу), **скопируйте** `liberation_nextturn.miz` в ту же папку
  `Missions` под другим именем, например `Kavkaz_hod05.miz`.
  Она появится в DCS в **МИССИЯ → My Missions** и в **Редакторе миссий**.
- Можно открыть миссию в **Редакторе миссий** и сохранить через
  **Файл → Сохранить как** в любое место — это тоже обычная миссия DCS.
- **Важно:** результаты для кампании засчитываются только из **актуальной**
  миссии хода, пока открыто окно ожидания. Сыгранная позже копия на кампанию не влияет.
- Не меняйте миссию хода в редакторе перед игрой в рамках кампании: имена групп
  и юнитов должны совпадать с тем, что ждёт Liberation.
- Для сетевой игры раньше требовалось пересохранять миссию в редакторе — **сейчас это не нужно**.

### Запись полёта (трек)
DCS после выхода из миссии предлагает **Сохранить трек** (`.trk`) — запись полёта для
просмотра. Треки лежат в `Saved Games\DCS\Tracks`. На кампанию они не влияют.

### Свои кампании, фракции, эскадрильи
Пользовательские файлы Liberation кладутся в `Saved Games\DCS\Liberation\`:
`Campaigns`, `Factions`, `Squadrons`. Инструкции — в вики проекта (раздел «Custom campaigns»,
«Custom factions»).

## 14. После миссии: результаты и следующий ход

1. Выйдите из миссии в DCS. Окно Liberation покажет **«Миссия окончена»** и счётчики:
   уничтожено ЛА, единиц на фронте, колонн, грузов, наземных объектов, захватов баз.
2. Нажмите **«Принять результаты»**. Откроется окно **«Итоги миссии»** с отчётом о потерях.
3. Начнётся следующий ход: прибудут покупки, сдвинется фронт, появятся сообщения
   в информационной панели.

Если Liberation **не заметил конец миссии**, нажмите **«Отправить вручную [для опытных]»**
и выберите файл `state.json`. Обычно он лежит в папке программы Liberation
(либо во временной папке Windows `%TEMP%`, либо в папке, указанной переменной
`LIBERATION_EXPORT_DIR`). Путь к нему пишется в `Saved Games\DCS\Logs\dcs.log`
(строка `DCS Liberation state will be written as json to ...`).

## 15. Наземная война: линия фронта, тактики, захват баз

Наземные войска сражаются на линиях фронта между связанными базами.
Тактика задаётся в меню своей базы → **Штаб сухопутных войск** → **Действия на линии фронта**.
Названия тактик остались английскими:

| Тактика | Что делают войска |
|---|---|
| **DEFENSIVE** — оборона | Держат позиции и обороняются средними группами |
| **AMBUSH** — засада | Оборона малыми группами; ПТУР и пехота с РПГ стоят на передовой вместе с бронёй |
| **AGGRESSIVE** — наступление | Танки и БМП сближаются с ближайшей группой противника и продвигаются до 16 км; если вражеская база ближе 16 км — атакуют её |
| **ELIMINATION** — уничтожение | Атакуют три ближайшие группы противника, после этого продвигаются до 16 км. Сначала уничтожение, потом продвижение |
| **BREAKTHROUGH** — прорыв | Большими бронегруппами рвутся вперёд до 35 км, при возможности атакуют базу. Продвижение важнее потерь |
| **RETREAT** — отступление | Немедленно отходят до 20 км; если своя база ближе — перегруппируются там |

БТР и ПТУР-установки двигаются осторожно и следуют за наступлением; артиллерия
стреляет по целям в радиусе и отходит при повреждениях.

Итог хода на фронте определяется потерями и тактикой: при большом перевесе
фронт сдвигается сильнее. Сводка приходит в информационную панель («Сводка с фронта»).

**Захват базы** работает по правилам DCS: в радиусе 5 морских миль от базы должна
быть ваша наземная техника и не должно быть техники противника. При захвате ЛА базы
отходят на ближайшую подходящую базу в радиусе 200 миль, наземные войска — на связанную
базу. Кто не смог отойти — захвачен и продан.

Включённые читы (Настройки → Меню читов) добавляют кнопки «ЧИТ: наступление»,
«ЧИТ: отступление», «ЧИТ: захватить» и т. п.

## 16. Переброска войск и эскадрилий

- **Эскадрильи**: окно **Авиакрыло** → двойной щелчок по эскадрилье → внизу выберите
  «Перебазировать в …». Перебрасывается вся эскадрилья.
- **Наземные войска**: меню базы → **Перебросить войска** → пункт назначения и
  количество → **Создать приказ на переброску**. Тип транспорта: **Авто** или
  **Авиаперевозка**.
- Купленная техника появляется на ближайшем заводе и сама едет к базе назначения
  (одна контрольная точка за ход).
- Способы: по дорогам (колонны), морем (грузовые суда), по воздуху (Airlift/Transport).
  Колонны и суда видны в миссии — их можно атаковать, и противник может атаковать ваши.
- Все переброски — кнопка **Переброски** на панели. Там же их можно отменить.

## 17. Экономика и автоматизация

- Доход каждый ход дают контрольные точки и **объекты**: заводы, склады, электростанции,
  нефтяные объекты и т. д. Подробно — **Бюджет → Финансы**.
- Уничтожая вражеские объекты, вы снижаете доход противника. Захваченные после взятия
  базы здания не ремонтируются — подумайте, прежде чем бомбить то, что собираетесь захватить.
- Автоматизация (Настройки → Управление кампанией → Автоматизация штаба):
  - ремонт ВПП выполняется первым;
  - до половины оставшихся денег уходит на технику для фронта (сначала туда,
    где меньше 30 единиц);
  - остаток — на ЛА для задач, которые не удалось спланировать из-за нехватки самолётов.

## 18. Настройки кампании

Кнопка **Настройки** на панели. Страницы:

**Сложность** — уровень ИИ своей стороны, противника, вражеской ПВО и техники
(Средний / Хороший / Высокий / Отличный); множители дохода; «Пилоты игроков не могут
погибнуть»; ПЗРК на фронте; без ночных миссий; ограничения миссии: метки в игре,
видимость на карте F10 (Всё / Туман войны / Только союзники / Только свой ЛА /
Только карта), внешние виды, упрощённая связь, оценка повреждений.

**Управление кампанией** — ограничение оружия по дате, рост уровня пилотов ИИ,
лимиты пилотов в эскадрильях, автоматизация штаба, автоматическое планирование пакетов
(Выключено / Никогда не назначать пилотов-игроков / Без предпочтений /
Предпочитать пилотов-игроков), управление тактикой на фронте.

**Генератор миссий**:
- *Командиры на поле боя* — слоты Game master, Tactical commander, JTAC/оператор,
  Наблюдатель (модуль Combined Arms).
- *Игровой процесс* — бесконечное топливо ИИ; возврат к состоянию до взлёта при
  прерывании; режим без ходов; **ускорение времени** (до запуска/руления/взлёта игрока,
  до IP, до первого контакта, вручную) и что делать при бое во время ускорения
  (пауза / расчёт боя / пропуск боя); Supercarrier; метки целей на карте; тёмный планшет;
  «Звенья игроков игнорируют TOT и появляются сразу»; тип старта ИИ по умолчанию;
  желаемая длительность миссии.
- *Производительность* — дым на фронте, артиллерия, ракетные удары, движущаяся техника,
  пехота, остовы уничтоженной техники, отсечение дальних юнитов (culling) и его дистанция.

Советы по производительности: самый действенный способ — меньше авиации (меньше
эскадрилий и их размер), снизить бюджеты и множители дохода, выключить дым,
пехоту и остовы техники, отключить Tacview.

**Меню читов** — показывать ATO красных, читы линии фронта, захвата баз,
состояния ВПП, деньги.

**Lua-плагины / Параметры Lua-плагинов** — включение и настройка плагинов.

## 19. Игра по сети и выделенный сервер

### Вы хостите сервер с того же компьютера
1. Запустите Liberation, затем DCS.
2. Назначьте пилотов-игроков для всех людей (по одному на каждого, раздел 11).
   Число слотов видно в **Макс. игроков**.
3. Нажмите **Взлёт**, затем в DCS: **МУЛЬТИПЛЕЕР → Новый сервер** → добавьте
   `liberation_nextturn.miz` из папки `Missions` → запуск.
4. По окончании остановите миссию на сервере и примите результаты в Liberation.

### Выделенный сервер на другом компьютере
1. На сервере вручную измените `<папка DCS>\Scripts\MissionScripting.lua`:
   закомментируйте три строки (поставьте `--` в начале):
   ```lua
   --sanitizeModule('os')
   --sanitizeModule('io')
   --sanitizeModule('lfs')
   ```
   Или замените файл файлом `resources\scripts\MissionScripting.lua` из папки Liberation.
   После каждого обновления DCS правку нужно повторять.
2. Задайте на сервере переменную окружения `LIBERATION_EXPORT_DIR` — папку, куда
   скрипт будет писать `state.json`. Перезапустите DCS после этого.
3. Сгенерируйте миссию на своём компьютере, скопируйте `liberation_nextturn.miz`
   на сервер и запустите.
4. После миссии скопируйте `state.json` с сервера к себе и нажмите
   **«Отправить вручную [для опытных]»**. Если окно ожидания закрыто — снова
   нажмите «Взлёт», окно появится.

## 20. Обновление DCS и DCS Liberation

- **DCS World** обновляется через апдейтер (ярлык «DCS World Update» или
  `<папка DCS>\bin\DCS_updater.exe`). Перед обновлением закройте Liberation.
  После обновления — сначала Liberation, потом DCS.
- Новая версия DCS может быть несовместима со старой версией Liberation (новые
  самолёты, изменения в pydcs). Смотрите в описании релиза Liberation, на какую версию
  DCS он рассчитан.
- **DCS Liberation**: скачайте новый русский релиз, распакуйте в новую папку.
  Старые кампании доигрывайте на старой версии (сохранения между основными версиями несовместимы).

## 21. Решение проблем

| Проблема | Что делать |
|---|---|
| После миссии Liberation не видит результат | Liberation был запущен после DCS, или DCS обновился. Перезапустите оба в правильном порядке. Сейчас — «Отправить вручную» и выберите `state.json` |
| «Не удалось изменить файл MissionScripting» | Запустите Liberation от имени администратора; проверьте путь к папке установки DCS (**Файл → Параметры**) |
| «Неверная папка установки DCS» | Укажите папку, в которой есть `bin` и `Scripts` (а не саму `bin`) |
| Миссия не появляется в DCS | Проверьте, что папка Saved Games в Liberation — та, которой пользуется DCS (`DCS` или старая `DCS.openbeta`) |
| Миссия не грузится, ошибка про мод | В мастере были отмечены моды, которых нет. Начните новую кампанию без них или установите моды |
| Не могу сесть в кабину | Звено ждёт своего времени старта. Подождите или включите «Звенья игроков игнорируют TOT…» |
| Низкий FPS | Раздел 18: меньше авиации, ниже бюджеты, отключить дым/пехоту/остовы, culling |
| Программа вылетает | **Справка → Показать журнал**; лог DCS: `Saved Games\DCS\Logs\dcs.log`; лог Liberation: `logs\liberation.log` в папке программы |
| Сохранение не открывается | Оно от другой основной версии Liberation — откройте его в той версии |

Об ошибках самой программы (не перевода) можно сообщить авторам: **Справка →
Сообщить об ошибке** (на английском, приложите сохранение).

## 22. Словарь: что значат английские обозначения

Интерфейс переведён, но некоторые названия остались английскими: это военные
термины, названия из DCS или значения, на которых завязаны сохранения и файлы кампаний.

### Типы задач звеньев (Задача)

| Обозначение | Расшифровка | Что делает звено |
|---|---|---|
| **BARCAP** | Barrier Combat Air Patrol — заградительный воздушный патруль | Патрулирует «ипподромом» над своим объектом и не пускает вражескую авиацию. Ориентирован к ближайшему вражескому аэродрому, патруль ~30 мин |
| **TARCAP** | Target Combat Air Patrol — патруль над целью | Патруль над вражеской целью, пока там работают остальные звенья пакета. Прибывает за 2 мин до сбора пакета. Плохой выбор рядом с вражескими ЗРК |
| **CAS** | Close Air Support — непосредственная авиационная поддержка | Работает по противнику на линии фронта, пока не кончится топливо (bingo) или оружие (winchester). Цель — линия фронта (правый щелчок по ней) |
| **BAI** | Battlefield Air Interdiction — изоляция поля боя | Уничтожает вражеские войска до подхода к фронту: группы техники, колонны (через «Отправляемые колонны» → «Атаковать») |
| **Strike** | Удар | Бомбит заданные координаты объекта (завод, склад, мост…). Атакует точки, а не юниты: движущуюся цель не поразит |
| **SEAD** | Suppression of Enemy Air Defenses — подавление ПВО | Подавляет РЛС цели противорадиолокационными ракетами (HARM) или ловушками, чтобы по ней отработали DEAD. TOT на 1 мин раньше пакета |
| **SEAD Escort** | Сопровождение подавления ПВО | Летит с пакетом и атакует любой ЗРК, который угрожает пакету по маршруту |
| **DEAD** | Destruction of Enemy Air Defenses — уничтожение ПВО | Уничтожает ЗРК (бомбы, ПТУР). Обычно идёт в паре с SEAD |
| **Escort** | Сопровождение | Прикрывает пакет от истребителей по маршруту, в районе цели не остаётся |
| **Fighter sweep** | Расчистка воздуха | За 5 мин до пакета вычищает истребители противника в районе цели |
| **Intercept** | Перехват | Перехват воздушных целей |
| **Anti-ship** | Противокорабельный удар | Пуск по группе кораблей с рубежа атаки. У кораблей сильная ПВО — нужно много ракет |
| **OCA/Aircraft** | Offensive Counter Air — удар по самолётам на земле | Ищет и уничтожает ЛА на стоянках вражеского аэродрома |
| **OCA/Runway** | Удар по ВПП | Разрушает полосу: нужно ~6000 фунтов фугасных бомб (12×Mk-82, 6×Mk-83, 3×Mk-84) или ~2000 фунтов проникающих (одна GBU-31v3). Аэродром без ВПП не может выпускать самолёты; ремонт 4 хода и $100M |
| **OCA Strike** | Так называется пакет из OCA/Aircraft или OCA/Runway | — |
| **AEW&C** | Airborne Early Warning & Control — ДРЛО и управление | Самолёт радиолокационного дозора (E-3, А-50 и т. п.) |
| **Refueling** | Дозаправка | Самолёт-заправщик |
| **Transport** | Транспорт | Авиаперевозка войск при переброске |
| **Air Assault** | Воздушный десант | Вертолёты высаживают пехоту для захвата точки. Нужен плагин CTLD |
| **Ferry** | Перегонка | Перелёт ЛА на другую базу |
| **Idle** | Простой | Без задачи |
| **No mission** | — | Пакет без задания (переведено как «Нет задания») |

## 23. Как обновляется русская версия

В этом репозитории настроена автоматика GitHub Actions — workflow **«Русский релиз»**
(`.github/workflows/russian-release.yml`):

1. **Раз в 7 дней** (по понедельникам в 09:00 МСК) проверяется последний релиз
   оригинального проекта [dcs-liberation/dcs_liberation](https://github.com/dcs-liberation/dcs_liberation/releases).
2. Если для этой версии ещё нет релиза `<версия>-ru`, на код этой версии
   накладывается русификация из ветки `russian`. В местах, где авторы изменили код,
   берётся их версия, чтобы программа не сломалась; там строки могут остаться английскими.
   Отчёт об этом — в описании релиза.
3. Переведённый код проверяется тестами и собирается под Windows.
4. Публикуется релиз «DCS Liberation <версия> (русская версия)» с архивом программы
   и исходниками.

Запустить проверку вручную: вкладка **Actions** → **Русский релиз** → **Run workflow**.
Там можно указать конкретную версию и включить пересборку.

Если сборка упала, GitHub пришлёт письмо владельцу репозитория. Перевод новых строк,
появившихся в новой версии, добавляется правкой ветки `russian`.
